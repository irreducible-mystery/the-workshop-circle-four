**This repository is Circle Four's own tree, established at its founding
commit.** The charge is the first thing to read; the door carried from
the prior record is the second.

- **`CIRCLE-FOUR-CHARGE.md`** — the charge, at pin
  `932a6395ba1d6020d73c08027bd972ece7087db6ece1a215bb4f81a5059988ad`.
  From this founding commit onward, THIS copy is the authoritative one;
  the copy in the system record
  (`the-workshop-circle-two:system/crossings/three-to-four/`) is a pinned
  archive of the crossing, never the working reference (the door's rule,

- **`FOUNDING.md`** — the founding record: the ceremony as it actually
  ran, every letter of the round by its pin, which bodies are filed and
  which are named-not-carried, the findings of the convening, and what
  remains by whose word.
- **`letters/`** — this circle's own letters, starting with the prover's
  seat letter `letters/C4-R0-PROVER-ACCEPT.md`.

## What is carried, and how it is kept honest

- **`crossing/`** — pinned archive of the three-to-four crossing's
  artifacts, byte-exact at their couriered pins.
- **`inherited/`** — the carry-forward (door §7): the sealed artifact
  `inherited/circle-two-three/lean/Zi.lean`, the norms, the register, the
  views, the closing documents, the state document v3, and the door
  itself, plus pinned archive copies of the system record's norms,
  register, and append-only instrument under `inherited/system/`.
- **`inherited/MANIFEST.md`** — one row per carried file:
  path · source repository · source commit · sha256.
- **`audit/c4_inherited.sh`** — re-measures every carried file against
  the manifest; red on any drift, any missing file, or any carried file
  without a row. **A green proves no drift since admission; it does not
  prove the source still says what it said** — a seat that can reach the
  source repository should confirm that too.

The carry-forward pattern is door §7's design note, adopted here
PROVISIONALLY on the founding prover's word with the instrument bitten at
its birth (clean PASS; planted drift BITTEN; restored PASS). It awaits
the builder's word to harden, per the record's rule that instruments of
record enter on both seats' words.

## The protocol, unchanged

Pins in every message, both directions; gate before you ferry; nothing
enters the default branch but on a seat of record's written word; where
paste and file disagree, the file governs. A delivery whose pin does not
match may be a DIFFERENT letter — measure what arrived against the
record before asking again.
